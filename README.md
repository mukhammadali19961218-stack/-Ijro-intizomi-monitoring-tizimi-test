# -Ijro-intizomi-monitoring-tizimi-test

«Issiqlik elektr stansiyalari» aksiyadorlik jamiyati Ijro intizomi monitoring va nazorat tizimi.

## Imkoniyatlar
- Boshqarmalar va rahbarlar bo'yicha ijro intizomi monitoringi
- Kechikkan va ijrodagi topshiriqlar statistikasi
- Excel orqali topshiriqlarni import va eksport qilish
- Rahbarlar va boshqarmalarni boshqarish (ID raqamlar, fotosuratlar)
- Administrator va kuzatuvchi rollari

## O'rnatish va ishga tushirish
```bash
npm install
npm start
```
Tizim http://localhost:3000 manzilida ishga tushadi.
